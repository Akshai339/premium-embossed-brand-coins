# Premium Embossed Brand Coins

A reusable image-generation plugin for premium investing-product renders: flat pale-silver coins, one low embossed brand mark, reeded sidewalls, and controlled studio reflections.

## Install

In a supported ChatGPT or Codex desktop environment, open **Plugins**, choose **Add from repository**, and use:

`https://github.com/Akshai339/premium-embossed-brand-coins`

Install **Premium Embossed Brand Coins**, then start a chat with one of the included prompts or invoke:

`$artifact-template-premium-embossed-brand-coins`

Plugin availability depends on the user’s ChatGPT plan and workspace permissions. If a standard ChatGPT chat does not offer plugin installation, paste the requested image brief and attach a visual reference when needed.

## Examples

- “Generate one Meta coin, facing almost straight toward the camera.”
- “Create five Netflix coins in a right-aligned 2.7:1 banner cluster.”
- “Write a prompt for an Amazon coin stack; use the attached image for composition only.”

## Visual rules

- Flat, smooth, borderless faces in a single pale-neutral silver.
- One centred, low, same-metal embossed logo per coin.
- Fine reeding only on the external sidewall.
- Soft feathered studio reflections; no harsh black hotspots.
- A composition reference never overrides the coin material system.
